# Test report: the SALTLINE logo and release 0.1.1, 2026-11-04

All results come from runs on 2026-11-04 (Sydney time) on one MacBook Air M4 (macOS 27.2). Nothing here is
estimated. Pictures and logs are in `Logo_0.1.1/`.

**Not tested:** the Windows build on Windows (no Windows machine was available; its icon was read out of the
executable on the Mac), and how Finder, the Dock and Windows Explorer show the icon. The macOS icon was checked
in the app's icon file, not on screen.

## 1. The problem

0.1.0 had no app icon. No icon had been assigned in Unity, so the Mac app's `Info.plist` named a
`PlayerIcon.icns` that the bundle did not contain, and macOS showed a blank icon. The main menu showed the name
in plain type, which at 1920 x 1080 ran past the edge of its panel.

## 2. What was made

- **The logo** (original, made for this project): an S drawn as the map's three lanes, joined like the salt
  works' pipes, with both ends cut at a slant, in the game's orange. Above 64 px a thin white horizon line runs
  through the middle lane. `ArtSource/Branding/make_logo.py` draws every version from one geometry: the app icon
  at 1024, 512, 256, 128, 64, 48, 32 and 16 px on Apple's 1024 grid, the menu logo, and the site's favicon and
  header SVG (`logo_sizes.jpg`).
- **App icon:** `Branding.cs` sets those files as the desktop icon for every size Unity asks for, and as the
  default icon. `ProjectConfigurator.Apply` calls it, so the icon survives a project setup.
- **Main menu:** the logo above the name; the name is smaller (78 px instead of 92 px) and fits its panel
  (`menu_1280.jpg`).
- **Website:** the logo beside the name in the header, and a new favicon.
- **Version 0.1.1**, network protocol unchanged (4).

## 3. Tests and builds

- **EditMode tests: 95 of 95 passed** (92 before, 3 new in `BrandingTests`: every desktop icon size has the
  SALTLINE icon at least as large as its slot, the default icon is the 1024 px one, and the menu stylesheet uses
  the logo).
- **Builds:** macOS and Windows release builds from commit `3e03dd2`, 0 errors, stamps clean.
- **Icons in the builds** (`icons_in_builds.jpg`): the Mac app contains `PlayerIcon.icns` with 16 to 1024 px
  images. The Windows executable's resources hold one icon group with nine 32-bit images (16, 24, 32, 48, 64, 96,
  128, 192 and 256 px), read out with a small PE reader and viewed.
- **Menu:** the Mac build started in batch mode and its menu was captured (`menu_1280.jpg`).
- **Site:** built and viewed locally at 1024 px and 375 px before publishing: the header logo loads, and nothing
  is wider than the screen at 375 px.
