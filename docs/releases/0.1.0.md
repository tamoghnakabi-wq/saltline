## First public test release

- 4v4 team deathmatch on Kappa Saltworks: first team to 50 kills, or the most kills after 10 minutes.
- Five weapons: VK-21 Halyard rifle, SMR-9 Wasp SMG, TS-12 Breaker shotgun and LR-338 Longreach sniper rifle as primaries; P-45 Brace pistol as the sidearm.
- Sprint, crouch, slide and jump; first- or third-person view.
- Online play through Unity Relay: one player hosts from the menu and up to seven others join, with no port forwarding. The host runs the match, and the match ends if the host leaves.
- macOS (Apple silicon) and Windows x64 builds share the same content and network protocol, so they are built to join each other's matches (not yet tested between the two, see below).
- Graphics presets from Low to Ultra, plus Laptop for thin-and-light machines (the default on Apple-silicon laptops).
- On first launch the game prepares its shaders in the main menu (3.5–5 s on a MacBook Air M4) so the first match does not freeze.
- The menu checks the website for a newer version when the game starts. When a release changes the network protocol, older versions are asked to update instead of finding no matches.

## Known limitations

- The Windows build has not been tested on Windows hardware yet. Online play has been tested between several copies of the game on one Mac, through Relay; players on separate machines, and Mac with Windows, have not been tested.
- The macOS app is not notarized by Apple, and the Windows executable is not code-signed, so both systems warn the first time you open the game.
- One map and one mode.
