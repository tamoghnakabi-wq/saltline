## The SALTLINE logo

- SALTLINE now has a logo: an S drawn as the map's three lanes, with the sea horizon running through the middle
  lane. It is the app icon on macOS and Windows (0.1.0 showed a blank icon) and sits above the name in the main
  menu.
- The name in the main menu no longer runs past the edge of its panel.

Same network protocol as 0.1.0 (4), so 0.1.0 and 0.1.1 can play together.

## Known limitations

- The Windows build has not been tested on Windows hardware yet. Online play has been tested between several copies of the game on one Mac, through Relay; players on separate machines, and Mac with Windows, have not been tested.
- The macOS app is not notarized by Apple, and the Windows executable is not code-signed, so both systems warn the first time you open the game.
- One map and one mode.
